Rebuild the Arabic share card

Regenerates public/images/og/ar-share-card.png, the Open Graph card served for every /ar route. Open this file in a browser, wait for the canvas below to draw, then use the button to download and replace that file.

Why this is a static image rather than a generated one. Every other share card on the site is drawn at request time by next/og. That renderer (Satori) shapes Arabic letters and joins them correctly, but performs no bidi reordering: it lays words out in source order, left to right, so every multi-word Arabic line comes out in reverse word order. Measured rather than guessed — rendering "أ بببببببب" puts the one-letter word on the left, where a browser puts it on the right. Setting direction: rtl changes nothing, and wordSpacing is ignored. A browser canvas has a real bidi implementation, so the card is drawn here instead and committed as a file.

If you change the copy, edit the strings below, reload, download, and commit the new PNG. Keep the strings identical to the approved Arabic in lib/translations.ts and the /ar page metadata — this card must not introduce copy that exists nowhere else.

Download ar-share-card.png

The committed file is quantised to a 256-colour palette, which takes it from roughly 175KB to 36KB with no visible change. The download here is the full-colour version; quantise before committing, for example:

python -c "from PIL import Image; Image.open('ar-share-card.png').convert('RGB').quantize(colors=256).save('ar-share-card.png', optimize=True)"
